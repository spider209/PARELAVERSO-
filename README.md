# Parrelaverso

Site literário estático baseado no PDF **Sinopses das Obras do Matthew**, de Matheus Parrela. Inclui 20 obras, capas extraídas do documento original, filtros por gênero, sinopses em janelas interativas, efeitos de movimento, layout responsivo e suporte a movimento reduzido.

## Executar
Abra `index.html` no navegador ou execute `python -m http.server 8000` na pasta do projeto.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub e envie todos os arquivos desta pasta para a raiz da branch `main`.
2. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**; salve.
3. O GitHub exibirá o endereço do site após a publicação. Para domínio próprio, configure em **Pages → Custom domain** e ajuste o DNS.

Conteúdo das obras e imagens: Matheus Parrela. Site apresenta obras anunciadas para publicação futura; não implica disponibilidade comercial.
As capas SVG da versão hospedada são ilustrações vetoriais estilizadas; o pacote ZIP original contém as capas extraídas do PDF.
